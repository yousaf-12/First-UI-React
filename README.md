# UI Design Project built with React.js

A modern and responsive UI built using 
React.js with component-based architecture.

# Tech Stack:
→ React.js (Vite)
→ Tailwind CSS
→ Component-based structure
→ Props for data passing

# Key Concepts Used:
→ Reusable Components
→ Props & Data Flow
→ Dynamic rendering with .map()
→ Clean folder structure

# Features:
→ Dynamic card rendering
→ Image cards with overlays
→ Clean modern UI design
